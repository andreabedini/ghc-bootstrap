# Rebasing the GHC 6.0 mhs work onto GHC 6.2.2 -- dry-run estimate

Static analysis only; no mhs was run. Working files: build/rebase622/ (pristine
ghc-6.0/ and ghc-6.2.2/ compiler trees, 6.0-current.patch, try622/ = 6.2.2 with
the patch applied, apply.log, build-order-6.2.2.txt, hsboot-6.2.2/).

## 1. Current 6.0 edit patch (6.0-current.patch)

diff -ruN pristine 6.0 vs build/ghc-6.0-run2/ghc/compiler, excluding non-edits:
103 files, 244 hunks (stale 6.0-run2.patch had 101 files). Extra files in the
working tree, excluded: prelude/primop-*.hs-incl (10) + prelude/primops.txt
(generated by genprimopcode), utils/ghc-pkg (symlink), .claude/.

Three files are wholesale regenerations, not edits: parser/Parser.hs (10 hunks),
parser/ParserCore.hs (8), main/ParsePkgConf.hs (9), re-emitted from the .y
sources by build/happy-mhs. That leaves 100 edited files / 217 edit hunks.

## 6. Estimate

Of the 217 hand edits (hunks) made for 6.0:
- 171 apply unchanged (160 clean, 11 harmless fuzz);
- 4 need trivial rework (UniqSupply CAF/genSym, TcRnDriver and TcRnTypes import
  lists, PrelInfo fuzz misplacement);
- 8 are no longer needed (fixed upstream);
- 34 are void because their files were replaced: Lex.lhs (26), StringBuffer.lhs
  (8). Their replacements are where the real work is.

Real work (Z), by size:
1. Lexer: make alex-generated parser/Lexer.hs portable (regenerate Lexer.x
   without -g after porting alexGetChar -> alexGetByte, or hand-convert the four
   "..."# tables) + Functor/Applicative/MonadFail for P. About the size of the
   old 26-hunk Lex.lhs job, different in kind.
2. StringBuffer shim: re-implement to the new 11-function API (smaller than now).
3. Regeneration steps already scripted for 6.0: Parser.y / ParserCore.y /
   ParsePkgConf.y via build/happy-mhs; primop-*.hs-incl from the changed
   primops.txt.pp via genprimopcode.

Trivial new items (Y): Digraph _scc_ x2, two new unspaced compositions
(CompManager, DriverState), CForeign shim, Config.hs version values,
TcMatches.hs-boot (tcGRHSsPat), DataCon.hs-boot (dataConInstOrigArgTys).

Supporting files: HsVersions.h unchanged in effect; 30/32 hs-boot verbatim,
2 one-liners; 16/16 run2 shims still needed, 1 rewrite (StringBuffer), 1 new
(CForeign); phase1 shims unchanged; build-order script reused as is (241
modules). Expect 6.2.2 to reach the same ~80% typechecking mark as 6.0 with a
few hours of work; the lexer is the only non-mechanical item.
